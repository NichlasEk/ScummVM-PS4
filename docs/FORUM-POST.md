# Unofficial native PS4 port of ScummVM — early testing

Hi! I've been working on a native PS4 port of ScummVM 2.9.1 using the
OpenOrbis toolchain.

I've tested Day of the Tentacle on my PS4 and confirmed that it runs.
The current build includes the SCUMM engine and controller-driven pointer
support. Game folders can be selected on USB or internal storage; USB
browsing has been tested in shadPS4 and needs further hardware testing.

No games or game data are included. Users must supply their own legally
obtained game files. Installation requires a homebrew-enabled PS4.

This is an early, unofficial port, not an official ScummVM release.
Broader compatibility and save/load testing are still needed. Feedback
from testers and ScummVM developers would be very welcome.
