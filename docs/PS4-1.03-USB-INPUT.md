# PS4 1.03: USB visibility and fine pointer control

The physical PS4 now opens Add Game without crashing (user screenshot), but
its root lists only bundled and internal games. The emulator supplies
/mnt/usb0 directly; this did not exercise console sandbox access.

## USB candidate

The browser checks /mnt/usb0..7, then app-local /usb0..7. If no USB is directly
reachable, the storage adapter uses the existing homebrew kernel service via
libjbc to map USB into the app sandbox with read-only nullfs mounts. Ordinary
app paths and credentials are restored after each operation. Only mounts
created by this process are released on normal exit. No formatting or writes
to the USB filesystem are performed by this adapter. Logs use [ps4-usb].

This requires a compatible already-running homebrew environment. It does not
install a console exploit. Kernel access failure is reported and returns to
the launcher. Physical hardware remains the necessary validation of this path;
emulator USB mounts cannot establish that the console sandbox mapping works.

Dependency source: bucanero/ps4-libjbc at
835fe016ff0ae5dd89b9249f39cc0fe093fd07dd, based on sleirsgoevy's libjbc.
https://github.com/bucanero/ps4-libjbc/tree/835fe016ff0ae5dd89b9249f39cc0fe093fd07dd
https://github.com/sleirsgoevy/ps4-libjbc

The build fetches this into ignored .tools and compiles locally; no binaries
or third-party source are committed. Local adaptations bound process traversal,
check credential setup, use read-only mounts, and namespace raw open/close
symbols so application libc calls retain their normal error handling.
The inspected upstream does not declare a license. Public redistribution of a
linked build needs clarification/replacement of this dependency in addition
to the existing release audit. This is a private hardware-test candidate.

## Pointer

The ScummVM virtual pointer now uses a quadratic radial response after the
existing deadzone: 10% deflection produces 1% maximum speed, 50% produces 25%.
Full deflection keeps the previous 2x maximum. Diagonals are capped and the
existing subpixel accumulator retains tiny movements; there is no forced
minimum multi-pixel step. R1 precision mode and the speed slider still apply.

The installed SDK SDL joystick object was independently disassembled and
confirmed to drop axis samples between -1000 and +1000, including neutral.
A private copy of libSDL2.a replaces only that joystick object with the
corrected driver; neutral is always delivered as zero. The SDK is unchanged.
Source is OpenOrbis/SDL-PS4 revision
7774cf3e7d04448c44d569c50d1f9a4532a2efe7, with its zlib license notice retained.
These changes affect analog-stick input and emulator mouse-to-stick input.
The user's exact physical input device is pending clarification.

The emulator input-setup script sets ps4_usb_sandbox=false in its own profile,
because shadPS4 does not implement the homebrew kernel service. Console
settings default to enabled. Use explicit --mount paths for emulator USB tests.
