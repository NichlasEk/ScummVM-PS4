Changes:

- Replace the generic full-frame RGB565 conversion/scaling path with an opaque
  lookup-table nearest-neighbour copier. Preserve viewport letterboxing, padded
  pitches and native destination color mapping. Unsupported formats or locked
  surfaces retain the SDL fallback. This targets a suspected rendering cost;
  physical PS4 performance improvement is not yet established.
- Cubic radial stick response for finer small deflections; full-scale speed is
  unchanged. Fractional movement and elapsed-time integration remain intact.
- Root status includes last scale/present durations in ms. Inside directories,
  show enumerated entries, failed stat classifications and errno. These fields
  distinguish successful root enumeration from child metadata/read failures.
  No USB mounting or filesystem classification policy was changed in 1.06.
