# PS4 1.07: hidden-file default and virtual keyboard

The user confirmed 1.06 worked well on physical PS4 and played a substantial
part of DOTT. They needed to enable Show hidden files to reach the game. The
report does not distinguish a filtering issue from the refresh caused by
changing that checkbox; preserve that uncertainty when investigating further.

The PS4 browser now enables hidden files on its first opening after upgrading.
A saved migration flag makes this a one-time change: later user preferences
are respected, including deliberately turning the checkbox off again.

Enable ScummVM's built-in virtual keyboard in the cross build and package the
upstream vkeybd_default.zip alongside the app data. The PS4 backend supplies
/app0/data as the session keyboard-pack path unless explicitly configured.
This uses ScummVM's existing keyboard implementation and controller mapping:
press the touchpad (JOY_BACK) to open it, move with the stick and click with
Cross. R1 remains precision movement. No console network service is needed.
The keyboard is opened manually; automatic text-field activation is not added.

To name a save: select/edit the save-name field, press the touchpad, enter text
on the virtual keyboard and submit it, then confirm the save dialog. The same
keyboard supplies keys for original game dialogs. Keyboard availability is
separate from a claim that every game's custom save dialog has been tested.

Build and package validation pass. Actual PS4 guest loads vkeybd_default.zip
and displays the keyboard over DOTT when the touchpad binding is pressed.
